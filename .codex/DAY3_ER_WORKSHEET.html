提示卡（做题时可以看）
  • 存别人的 id = 普通列；外键 = 额外声明"这个 id 必须真实存在"，数据库当保安。
  • 索引：主键自带；经常出现在 WHERE 里的列建索引；多列一起查建联合索引（最左前缀）；索引不是越多越好——每个索引都拖慢写入。
  • 唯一约束 = 全表只许一份，重复插入直接报错；CHECK = 列级规则（如 remaining >= 0）。
  • 判定关系用一句话：一个 A 有几个 B？一个 B 有几个 A？
  • 10-12 号表（幂等/Outbox/审计）后面几周才登场，关系栏写"占位"即可。

任务 2：你的第一批真 SQL

写错了没关系，报错信息就是教材。质量标准对照下面的 slot 示范：字段带 COMMENT、有唯一约束、有索引。

点开看 slot 示范（对照质量用，不许抄成答案） 
CREATE TABLE slot (
  id           BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  schedule_id  BIGINT UNSIGNED NOT NULL COMMENT '所属排班',
  period       VARCHAR(16)  NOT NULL COMMENT '时段：AM/PM',
  start_time   TIME NOT NULL,
  end_time     TIME NOT NULL,
  total_count  INT NOT NULL COMMENT '本场总号数，如 24',
  remaining    INT NOT NULL COMMENT '剩余号数——防超卖主战场',
  status       VARCHAR(16) NOT NULL DEFAULT 'OPEN' COMMENT 'OPEN可约/LOCKED停诊',
  created_at   DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_schedule_period (schedule_id, period),
  KEY idx_status (status),
  CONSTRAINT chk_remaining CHECK (remaining >= 0)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='号源池';
