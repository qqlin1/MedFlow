# 预约与患者院内档案交付

更新时间：2026-10-21。最新状态以本文、[业务台账](BUSINESS_PROGRESS.md)和[测试报告](05-test-report.md)为准。M0是历史基线，当前增量已经实现并部署，不代表手册全部远期阶段都已完成。

## 现在可以自己点的内容

1. 患者从科室进入，或按姓名/擅长找医生；查看职称、擅长和简介后选择日期、上午/下午时段和就诊人。换科室、医生或日期会清掉旧选择，号源按后端实际余量显示。
2. 提交后由患者自行确认，到实际窗口自行签到。管理员不审核/拒绝患者预约。医生排班由管理员分配，医生无需报名。原有幂等、截止和容量规则继续生效。
3. “我的预约”和工作台最近预约直接显示日期、时段、医生、科室、诊室、就诊人。摘要每页批量查询，失败时保留预约并单独重试，不逐行发请求。
4. 管理员在医生列表维护公开资料。MySQL事务提交后删除详情缓存；回滚保留，Redis故障走已有受控降级。
5. 患者在“就诊人”点姓名/查看就诊档案；医生从本人预约或候诊姓名进入。同一就诊人按日期查看不同医生已完成病历、已提交处方、药品快照、账单和操作时间线。家属分档，其他医生草稿隐藏，历史只读，管理员无默认病历正文权限。
6. 演示目录补齐内科/外科/皮肤科三名虚构医生及未来号源；同一“演示·候诊一（虚构）”有林医生、周医生两次历史。保留原doctor绑定、已操作状态和管理员后来修改的简介。跨天按数据库当天补缺，开诊前不伪造未来签到。
