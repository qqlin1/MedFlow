# 业务边界与操作流程

MedFlow 是单院门诊教学演示系统，保留现有单体增量改造。用户最终确定：**患者自助确认预约、自助签到**。不引入管理员审核或 REJECTED。管理员可准备科室/诊室/医生、创建发布排班和受限停诊；医生查看自己的排班、预约、候诊，填写本次病历；患者管理本人/家属就诊人和各自记录。

## 患者路径

按科室预约：科室→医生资料→日期、上午/下午、具体时段→就诊人→核对提交→在截止前确认。找医生预约：全院姓名/擅长搜索，可筛科室→医生资料→同样后续步骤。内科、外科、皮肤科就是科室，不再建立重复的“项目层”。

选择医生前先展示职称、擅长和简介；无资料显示暂未维护。换科室/医生/日期须清理旧选择，迟到响应不能覆盖新医生。号源余量以提交事务为准，不以页面展示作成功承诺。没有真实挂号费模型，不显示臆造收费。

预约创建占位：PENDING_CONFIRMATION→患者确认 BOOKED；有效取消变 CANCELLED、未确认超时变 EXPIRED，才回补容量一次。确认不再次扣容量。

## 到院与医生路径

已确认预约在就诊当天、时段开始前30分钟至结束前，可自助签到。签到新建一条 WAITING Encounter，同预约重复签到复用同条接诊。预约仍是 BOOKED，接诊状态另外维护。

医生 WAITING→IN_PROGRESS→保存病历→COMPLETED；也可把未开始的 WAITING 标为 SKIPPED。过号本版不可补叫。医生只能同时接诊一位，病历保存有版本控制；主诉/诊断未保存完整不能完成，处方草稿未提交/放弃也不能完成。

## 院内档案

患者从就诊人或单次预约打开全部历史。每位家属是独立 patientId。医生从属于自己的已确认预约，或属于自己的既有接诊进入，只读该患者在本院的已完成病历、已提交处方和账单。

本教学版保留关联预约/接诊关系的医生可持续查阅该患者院内历史，尚无独立授权到期或撤销模型。锚点若已有接诊，接诊医生必须与当前锚点排班医生一致，错配不授权。不能任意传 patientId 开放全库；不能修改别的医生病历；所有历史接口隐藏未完成正文/处方草稿。管理员不默认读取病历正文。

未实现化验、影像、跨院记录、过敏史长期摘要、复杂病历模板、医保和真实支付。简版药品、处方、模拟缴费与统计作为已授权扩展保留；Redis只做公开医生详情，MQ暂缓。
