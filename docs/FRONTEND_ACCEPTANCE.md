## 当前能力边界

当前后端没有医生业务、用户注册、资源编辑删除、管理员排班目录和撤回排班 API，页面也没有提供这些操作。排班列表是按账号保留的最近 100 条本机记录，发布状态不能自动同步其他终端；支持通过已知排班 ID 发布已有草稿。
